# marusho

Order page for Marusho (金沢屋) food delivery to guests of accommodations in Nagiso (Kashiwaya Inn, MOUNTAinn Nagiso, Akari, Ame Nakasendo, Yama Inn and more).

Guests tick menu items and quantities, choose their place, enter the date, delivery time and name, press **Confirm**, and get a WhatsApp link (+81 80-8913-5569) with the finished order message — they just press Send.

- Page: `src/app/page.tsx` / form, places, menu, prices, delivery times: `src/app/OrderForm.tsx`
- Menu with photos (PDF): `public/menu.pdf`

```bash
npm install
npm run dev
```
